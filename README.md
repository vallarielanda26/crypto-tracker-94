# Crypto Tracker 94

Crypto Tracker 94 is a Python-based application designed to help users monitor the real-time prices of various cryptocurrencies. With its easy-to-use interface and powerful features, this tool is perfect for both seasoned traders and newcomers to the crypto space.

## Features

- **Real-Time Price Monitoring:** Track the latest prices of over 1500 cryptocurrencies from multiple exchanges.
- **Custom Alerts:** Set personalized price alerts for your favorite cryptocurrencies to stay informed about market changes.
- **Historical Data Analysis:** Access historical price data and perform in-depth analysis to make informed trading decisions.
- **Cross-Platform Compatibility:** Built with Python, this application runs seamlessly on Windows, macOS, and Linux.

## Installation

To get started with Crypto Tracker 94, you'll need to have Python 3.6 or higher installed on your system. Follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/Developer/crypto-tracker-94.git
   ```
   
2. Navigate to the project directory:
   ```bash
   cd crypto-tracker-94
   ```

3. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Basic Usage Example

Once the installation is complete, you can start the application by running the following command in your terminal:

```bash
python main.py
```

After launching, you can view real-time prices of your desired cryptocurrencies and set up alerts by following the on-screen instructions.
